# Critère *Vulnérabilités non corrigées*

## Objectif

Est-ce que le projet contient des vulnérabilités publiées mais non corrigées ? 

## Actions

- Rechercher les bases de données de vulnérabilités publiques (ex. NVD, CVE, GitHub Security Advisories) pour le projet.
- Vérifier la présence de vulnérabilités publiées et non corrigées.
- Évaluer la criticité des vulnérabilités non corrigées.
- Vérifier la durée pendant laquelle les vulnérabilités restent non corrigées.
- Vérifier la présence de mesures d'atténuation documentées pour les vulnérabilités non corrigées.

## Notation

Note entre 0 et 20 :
- 0 : vulnérabilités critiques publiées et non corrigées.
- +5 : aucune vulnérabilité critique non corrigée.
- +5 : vulnérabilités de criticité moyenne corrigées dans un délai raisonnable.
- +5 : mesures d'atténuation documentées pour les vulnérabilités en attente de correction.
- +5 : processus actif de suivi et de correction des vulnérabilités.
