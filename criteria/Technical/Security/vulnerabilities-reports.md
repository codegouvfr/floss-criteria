# Critère *Signalement des failles*

## Objectif

Le projet dispose-t-il d'un processus de signalement des failles et traite-t-il les vulnérabilités rapportées ?

## Actions

- Rechercher un fichier SECURITY.md ou un canal de signalement des vulnérabilités.
- Vérifier la présence d'instructions claires pour signaler une faille de sécurité.
- Analyser le temps de réponse moyen aux signalements de vulnérabilités.
- Vérifier que les vulnérabilités signalées sont corrigées dans un délai raisonnable.
- Vérifier que les vulnérabilités corrigées sont documentées dans les notes de version.

## Notation
Note entre 0 et 20 :
- 0 : aucun processus de signalement des failles.
- +5 : canal de signalement des failles disponible et documenté.
- +5 : temps de réponse aux signalements acceptable.
- +5 : vulnérabilités corrigées dans un délai raisonnable.
- +5 : documentation des corrections dans les notes de version.
