# Critère *Gestion du code sécurisée*

## Objectif

Le code du projet est-il stocké et transmis de manière sécurisée ? 

## Actions

- Vérifier que le code du projet est hébergé sur une ou des plateformes sécurisées.
- Vérifier que les transmissions de données utilisent des protocoles chiffrés (TLS, HTTPS).
- Vérifier que la modification des données est soumis à des mécanismes d'authentification et d'autorisation.

## Notation
Note entre 0 et 20 :
- 0 : aucune mesure de sécurisation des données.
- +10 : données hébergées sur des plateformes sécurisées.
- +5 : transmissions de données chiffrées (TLS, HTTPS).
- +5 : modification du code soumis à authentification et autorisation.
