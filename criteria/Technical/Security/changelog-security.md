# Critère *Documentation des corrections de sécurité*

## Objectif

Les corrections de sécurité sont-elles documentées dans les publications de release ?

## Actions

- Rechercher un fichier de journal des modifications (CHANGELOG, CHANGES, RELEASES).
- Vérifier que les vulnérabilités corrigées sont mentionnées dans les notes de version.
- Vérifier que les corrections de sécurité sont associées à des identifiants CVE.
- Vérifier que les notes de version indiquent la criticité des vulnérabilités corrigées.

## Notation
Note entre 0 et 20 :
- 0 : aucune documentation des corrections de sécurité.
- +5 : journal des modifications présent et maintenu.
- +5 : vulnérabilités corrigées mentionnées dans les notes de version.
- +5 : identifiants CVE associés aux corrections.
- +5 : criticité des vulnérabilités indiquée.
