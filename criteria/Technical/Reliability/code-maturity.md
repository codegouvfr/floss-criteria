# Critère *Maturité du code*

## Objectif

Le code est-il suffisamment mature pour être déployé en production à l'échelle visée ?

## Actions

- Identifier la présence de beta, l'âge du projet. 
- Rechercher des retours d'utilisateurs ou de témoignages sur l'utilisation en production.
- Identifier les cas d'usage en production documentés ou connus.
- Vérifier la présence de tests de non-régression couvrant les fonctionnalités critiques.
- Évaluer la maturité du code à partir de la complexité et de la maintenabilité mesurées.

## Notation
Note entre 0 et 20 :
- 0 : projet trop récent ou insuffisamment testé pour une mise en production.
- +5 : projet présent depuis au moins un an avec des versions stables.
- +5 : retours d'utilisateurs positifs ou cas d'usage en production documentés.
- +5 : tests de non-régression couvrant les fonctionnalités critiques.
- +5 : code suffisamment mature et maintenable pour une mise en production.
