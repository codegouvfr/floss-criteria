# Critère *Dépendances des données*

## Objectif
Est-ce que le logiciel dépend de données extérieures à lui pour fonctionner ? Est-ce que ces données sont libres ou a minima gratuits ?

## Actions
- Établir la liste des données dont dépend l'exécution du logiciel d'après la documentation d'installation. 
- Pour chaque service listé, déterminer si cette dernière est libre ou a minima gratuite. 

## Notation
0 : certaines données nécessaires sont propriétaires 
+1 : toutes les données sont libres
