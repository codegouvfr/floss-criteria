# Critère *RGESN*

## Objectif

Le projet respecte-t-il les critères du référentiel général d'écoconception de services numériques ?

## Actions

- Rechercher une référence explicite au RGESN dans la documentation du projet.
- Vérifier la conformité avec les exigences du RGESN applicables au périmètre du projet.
- Évaluer la prise en compte de la sobriété numérique dans les choix techniques.
- Analyser la présence de mesures ou d'indicateurs de sobriété numérique.

## Notation
Note entre 0 et 20 :
- 0 : aucune référence au RGESN dans le projet.
- +5 : référence explicite au RGESN dans la documentation.
- +5 : critères RGESN pertinents identifiés et adaptés au projet.
- +5 : mesures ou indicateurs de sobriété numérique présents.
- +5 : conformité démontrée avec les exigences RGESN applicables.
