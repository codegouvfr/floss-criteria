# Critère *Couverture des tests*

## Objectif

La couverture de code des tests est-elle mesurée et affichée ?

## Actions

- Rechercher un outil de mesure de couverture de code.
- Vérifier que le rapport de couverture est généré lors des exécutions de tests.
- Vérifier que le rapport de couverture est accessible (badge, page CI, fichier de rapport).
- Analyser le niveau de couverture global du projet et par module.
- Vérifier que le seuil de couverture minimal est défini et respecté.

## Notation
Note entre 0 et 20 :
- 0 : aucun outil de mesure de couverture configuré.
- +5 : outil de mesure de couverture présent et configuré.
- +5 : rapport de couverture généré automatiquement.
- +5 : rapport accessible et consultable par les contributeurs.
- +5 : seuil de couverture minimal défini et respecté.
