# Critère *Automatisation des tests*

## Objectif

Les tests du projet sont-ils exécutables de manière automatique ?

## Actions

- Vérifier la présence de commandes ou scripts permettant de lancer les tests.
- Identifier le framework de test utilisé et vérifier qu'il est correctement installé et configuré.
- Tester l'exécution des tests pour constater qu'ils passent sans intervention manuelle.
- Vérifier la présence de documentation sur l'exécution des tests.

## Notation
Note entre 0 et 20 :
- 0 : aucun moyen d'exécuter les tests de manière automatique.
- +5 : commandes ou scripts de lancement des tests disponibles.
- +5 : framework de test correctement installé et configuré.
- +5 : les tests et leur lancement sont bien documentés. 
- +5 : les tests passent sans intervention manuelle.
