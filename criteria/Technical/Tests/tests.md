# Critère *Présence de tests*

## Objectif

Le projet dispose-t-il de tests maintenus ?

## Actions

- Rechercher un répertoire ou des fichiers de tests dans le dépôt du projet.
- Vérifier la présence de documentation décrivant le jeu de tests et leur exécution.
- Identifier le framework de test utilisé et sa pertinence par rapport au langage du projet.
- Vérifier que les tests sont versionnés avec le code source et évoluent conjointement.
- Évaluer la diversité des tests (unitaires, d'intégration, fonctionnels).

## Notation
Note entre 0 et 20 :
- 0 : aucun test présent dans le projet.
- +5 : tests présents et versionnés avec le code source.
- +5 : documentation du jeu de tests et de leur exécution disponible.
- +10 : diversité des tests (unitaires, intégration, fonctionnels).
