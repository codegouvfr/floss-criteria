# Critère *Commentaires du code*

## Objectif

Est-ce que le code est correctement commenté pour être facilement analysable et maintenable ?

## Actions

- Mesurer automatiquement la présence et le volume des commentaires dans le code. 
- Vérifier la présence de commentaires expliquant le pourquoi des choix et des parties complexes. 
- Évaluer la qualité des commentaires (pertinence, clarté, absence de commentaires obsolètes ou trompeurs) sur un nombre de fichiers exemples. 
- Vérifier la cohérence entre les commentaires et le code réellement implémenté sur un nombre de fichiers exemples. 

## Notation
Note entre 0 et 20 selon la qualité des commentaires :
- 0 : code non commenté ou commentaires inexistants. 
- +5 : commentaires présents et mesurés. 
- +5 : commentaires expliquant les parties complexes et les choix importants. 
- +5 : commentaires clairs, pertinents et à jour par rapport au code. 
- +5 : documentation développeur complète et cohérente.
