# Critère *Taille du code*

## Objectif

Est-ce que la taille du code est cohérente face aux fonctionnalités proposées ?

## Actions

- Mesurer automatiquement la taille du code :
  - Nombre de lignes de code (même hors commentaires et lignes vides). 
  - Nombre de fichiers. 
  - Nombre de classes, de fonctions et de modules. 
- Rapporter la taille au périmètre fonctionnel du logiciel. 
- Identifier les parties du code anormalement volumineuses au regard de leur rôle. 
- Vérifier l'absence de code dupliqué ou de fichiers démesurés. 
- Évaluer si la taille observée reste compatible avec une maintenance visée. 

## Notation
Note entre 0 et 20 selon la maîtrise de la taille du code :
- 0 : taille excessive ou disproportionnée au regard du périmètre fonctionnel. 
- +5 : taille mesurée de manière fiable (lignes, fichiers, classes, fonctions). 
- +5 : taille en rapport avec le périmètre fonctionnel du logiciel. 
- +5 : absence de parties anormalement volumineuses ou de code dupliqué. 
- +5 : taille restant compatible avec une maintenance visée.
