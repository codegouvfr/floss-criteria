# Critère *Standards du code*

## Objectif

Est-ce que le code suit les normes et standards des langages utilisés ?

## Actions

- Identifier les standards et conventions définies pour chacun des langages du projet (guide de style, norme officielle, etc.). 
- Analyser automatiquement le code avec un linter configuré pour ces standards. 
- Vérifier la présence et la qualité de la configuration du ou des linters. 
- Mesurer le taux de conformité du code aux standards retenus. 
- Évaluer la cohérence du style de code entre les différents fichiers et contributeurs. 

## Notation
Note entre 0 et 20 selon la conformité aux standards :
- 0 : code ne suivant aucune norme ou standard identifiable. 
- +5 : standards ou conventions des langages identifiés et documentés. 
- +5 : linter configuré et utilisé de manière visible. 
- +5 : taux de conformité élevé du code aux standards retenus. 
- +5 : style de code homogène sur l'ensemble du projet.
