# Critère *Complexité du code*

## Objectif

Est-ce que le code est complexe pour un humain ?

## Actions

- Pour un projet, on va mesurer les éléments suivants :
  - Nombre de fonctions 
- Pour chaque fonction du projet, on va mesurer les éléments suivants : 
  - Complexité cognitive du code
  - Nombre de lignes de code
  - Nombre de lignes de commentaires
  - Nombre de paramètres 
  - Nombre de sorties 
  - Lisibilité du nom de la fonction 
  - Documentation de la fonction 
  - Documentation des paramètres et retours de la fonction 
  - Lisibilité et cohérence des noms de variables
  - La bonne utilisation des variables : une variable = un usage
