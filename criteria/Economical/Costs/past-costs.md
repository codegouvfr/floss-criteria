# Critère *Coûts passés*

## Objectif

Quels sont les coûts déjà engagés dans le développement et le fonctionnement du projet ?

## Actions

- Recenser les investissements financiers déjà réalisés dans le projet.
- Évaluer les ressources humaines mobilisées (heures de travail, nombre de contributeurs).
- Identifier les subventions, dons ou financements déjà perçus.
- Évaluer les coûts d'infrastructure déjà engagés (hébergement, outils, services).
- Comparer les coûts passés aux résultats obtenus (avancement du projet, fonctionnalités livrées).

## Notation
Note entre 0 et 1 :
- 0 : les coûts dépassent mes prévisions. 
- +1 : les coûts ne dépassent pas mes prévisions.
